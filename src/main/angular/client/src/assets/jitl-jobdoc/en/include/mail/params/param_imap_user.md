## Argument: mail.imap.user
<article id="mail.imap.user">

Specifies the user account used for connections to the IMAP mail server.

The user account frequently is specified from an e-mail address.

[](include:include/common/notes/note_param_order.md)

- `mail.imap.user` from system properties
- `mail.user` from job argument or order variable
- `mail.user` from system properties
</article>
