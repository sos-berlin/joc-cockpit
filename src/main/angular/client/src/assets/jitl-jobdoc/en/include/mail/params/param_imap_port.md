## Argument: mail.imap.port
<article id="mail.imap.port">

Specifies the IMAP mail server port.

The default port depends on the connection using SSL (143) or not (993), see *mail.imap.ssl.enable* argument.

[](include:include/common/notes/note_param_order.md)

- `mail.imap.port` from system properties
- `mail.port` from Job argument or order variable
- `mail.port` from system properties
</article>
