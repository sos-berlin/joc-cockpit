## Argument: mail.pop3.port
<article id="mail.pop3.port">

Specifies POP3 mail server port.

The default port depends on the connection using SSL (993) or not (110), see *mail.pop3.ssl.enable*.

[](include:include/common/notes/note_param_order.md)

- `mail.pop3.port` from system properties
- `mail.port` from job arguments or order variables
- `mail.port` from system properties
</article>
