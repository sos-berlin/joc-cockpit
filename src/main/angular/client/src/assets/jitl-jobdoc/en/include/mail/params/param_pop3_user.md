## Argument: mail.pop3.user
<article id="mail.pop3.user">

Specifies the user account for connections to the POP3 mail server.

The user account frequently is specified from an e-mail address.

[](include:include/common/notes/note_param_order.md)

- `mail.pop3.user` from system properties
- `mail.user` from job arguments or order variables
- `mail.user` from system properties
</article>
