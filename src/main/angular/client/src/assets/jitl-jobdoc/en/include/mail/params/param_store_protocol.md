## Argument: mail.store.protocol
<article id="mail.store.protocol">

Specifies the protocol (POP3 or IMAP) of the mail server.

If the system property *mail.store.protocol* is set, then the argument is not required.

Allowed values:

- `pop3`: the *mail.pop3.\** arguments must be used for the connection to the mail server
- `imap`: the *mail.imap.\** arguments must be used for the connection to the mail server
</article>
