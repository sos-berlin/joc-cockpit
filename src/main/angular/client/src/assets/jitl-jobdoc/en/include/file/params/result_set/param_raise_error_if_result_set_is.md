## Argument: raise_error_if_result_set_is
<article id="raise_error_if_result_set_is">

Specifies if an error should be raised if the size of the result set matches the expectations.

Example:

Assume that the *raise_error_if_result_set_is* argument specifies the `ne` value and the *expected_size_of_result_set* argument value is `1`. If the number of hits is not equal to 1, then an error will be raised.
</article>
