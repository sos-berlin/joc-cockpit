**Valid values**

| Value | Description |
| :-------- | :------- |
| 0 | The value of the argument has no effect and the argument is not part of the filter. |
| seconds | The number of seconds. |
| hours:minutes | 01:15 is understood as 1 hour and 15 minutes. |
| hours:minutes:seconds | 01:15:10 is to understood as 1 hour, 15 minutes and 10 seconds. |
