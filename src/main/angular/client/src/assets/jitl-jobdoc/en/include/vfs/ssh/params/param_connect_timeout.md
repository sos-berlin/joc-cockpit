## Argument: connect_timeout
<article id="connect_timeout">

Limits the waiting period in seconds for a connection to a remote host to be established.

Possible values include:

- `0`: no timeout applied (default).
- `<n>s`: duration in seconds, for example `30s`.
- `<n><unit> <n><unit>`: combined values (with blank as separator) as in `1m 30s`.
</article>
