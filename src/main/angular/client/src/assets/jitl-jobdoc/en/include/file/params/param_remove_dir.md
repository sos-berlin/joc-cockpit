## Argument: remove_dir
<article id="remove_dir">

Specifies if empty sub-directories should be removed.

All sub-directories specified by the *file* argument will be removed if they match the *file_spec* argument value.
Sub-directories will be removed only if they are empty.

The directory specified with the *file* argument will not be removed.

The argument is only effective, if the *file* argument specifies a directory.
</article>
