## Argument: mail_source_folders
<article id="mail_source_folders">

Specifies the source folders in the mail server for processing of incoming mail.

The path can be a folder name such as `Drafts` or a folder hierarchy such as `public/com/Junk`. The path is considered being case sensitive.

More than one folder is concatenated by a semicolon. Folders are processed in the order of occurrence with the argument.
</article>
