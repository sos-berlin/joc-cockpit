**Values for file size**

| Values | Explanation |
| :----- | :----- |
| -1 | The value of the argument has no effect and the argument is not part of the filter. |
| number | The number indicates the size in bytes, for example 40 means 40 bytes. |
| numberKB | The number indicates the size in kilobytes as in `20KB`. |
| numberMB | The number indicates the size in megabytes as in `10MB`. |
| numberGB | The number indicates the size in gigabytes as in `5GB`. |
