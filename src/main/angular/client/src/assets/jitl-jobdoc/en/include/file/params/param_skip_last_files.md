## Argument: skip_last_files
<article id="skip_last_files">

Specifies the number of files to be removed from the bottom of the result set used for file operations.

The files will be removed from the bottom of the result set that is created by applying the *sort_criteria* and *sort_order* arguments. Files removed from the result set will be excluded from file operations.

The result set is sorted according to the arguments:

- *sort_criteria*
- *sort_order*
</article>
