## Argument: skip_first_files
<article id="skip_first_files">

Specifies the number of files to be removed from the top of the result set used for file operations.

Files will be removed from the top of the result set that is created by applying the *sort_criteria* and *sort_order* arguments. Files removed from the result set will be excluded from file operations.

The result set is sorted according to the arguments:

- *sort_criteria*
- *sort_order*
</article>
