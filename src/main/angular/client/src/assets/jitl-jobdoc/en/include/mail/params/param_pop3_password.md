## Argument: mail.pop3.password
<article id="mail.pop3.password">

Specifies the password used by the user account connecting to the POP3 mail server.

The default port depends on the connection using SSL (993) or not (110), see *mail.pop3.ssl.enable*.

[](include:include/common/notes/note_param_order.md)

- `mail.pop3.password` from system properties
- `mail.password` from job arguments or order variables
- `mail.password` from system properties
</article>
