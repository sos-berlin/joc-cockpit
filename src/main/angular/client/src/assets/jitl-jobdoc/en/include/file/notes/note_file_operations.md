**File Operations**

The category of "File Operations" includes commonly used operations such as copying, renaming, moving and deleting files.
File Operations are available from Java for all platforms supported by JS7 Agents.

In comparison with specific operating system commands such as copy, cp, move, mv, del and rm, which behave differently on different operating systems, the handling and behavior of the File Operation jobs is identical on all supported platforms.

Most job implementations support *regular expressions* for filtering of files that should be processed.

File operations are used in workflows, for example, when receiving files by SFTP, renaming the files and transferring the files to some other location.
