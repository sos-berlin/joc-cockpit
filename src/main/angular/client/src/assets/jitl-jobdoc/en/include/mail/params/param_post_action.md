## Argument: mail_post_action
<article id="mail_post_action">

Specifies the post-prcessing actions for incoming maill.

One of the following actions can be specified:

- `none`: no action
- `mark_as_read`: marks the mail as being read
- `copy`: copies the mail to another mail folder specified by the *mail_target_folder* argument
- `move`: moves the mail to another mail folder specified by the *mail_target_folder* argument
- `delete`: deletes the mail
</article>
